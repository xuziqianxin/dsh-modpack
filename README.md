# dsh-modpack

把 DSH 的插件开关变成「**整合包**」：一个**常开白名单**（公共插件）+ 若干个可切换整合包。
切到某个整合包，DSH 就打开它里面列的插件、关掉其余插件，并且**当场生效**。

## 它做了什么

DSH 本来就能一个个开/关插件。整合包是这层开关之上的编排：

- **公共整合包**（`always: true`）——白名单，任何整合包都自动带上；也可以整体关掉。
- **整合包**——一份插件名单。切换 = 「公共 ∪ 本整合包」的插件全部开启，其余可切换插件全部关闭。
- **受保护插件**——DSH 基座、插件管理器自身、本插件：永远开启，不参与勾选，也不会被关掉。

底层不重写任何配置：真正执行开关的是 DSH 自带的 `pluginManager.setBundleEnabled()`，
所以行为和设置页里手动拨开关完全一致（桌面端有 hmr，改完立刻生效）。

## 用起来

侧边栏 **插件** → 顶部标签栏里的 **整合包**（和「发现」并排）。

1. 第一次打开是一张空白白名单。先点「从当前配置另存为整合包」，把你现在的插件状态存成第一个整合包。
2. 想给公共白名单加插件，就把它勾进「公共插件」那个整合包。
3. 想做第二个使用场景，新建一个整合包、勾几个插件，切过去即可。

切换成功后界面会刷新一次，让新装上的前端插件一起就位。个别插件（比如带原生依赖的）
必须重启 DSH 才能完全生效，这时候界面会单独列出来 —— 那种情况 DSH 自己也需要重启，整合包做不到。

## 数据

`$DSH_HOME/dsh-modpack/state.json`（默认 `~/.dsh/dsh-modpack/state.json`）：整合包定义、
当前整合包、最近一次切换的结果。删掉它会退回「什么都还没配」的初始状态，不改动任何插件。

## 接口

内部 HTTP 接口在 `/api/dsh-modpack/*`：`state` 读取状态，`switch` 切换整合包，`pack/save|delete|adopt` 维护整合包，`common` 开关常开白名单。只有本插件的界面会调用它们。

## 边界

- 只编排**已经装好**的插件；装插件仍然走插件页/插件市场。
- 不改 `package.json` 的依赖，不装包，不重启 DSH。
